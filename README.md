# Forma I - Derecho Penal (Repaso 2do Ciclo)

Sitio de repaso y herramientas didácticas para el módulo **Instituciones Fundamentales del Derecho Penal de Forma I** (Programa: Formación Inicial para la Función Judicial - Consejo de la Magistratura, Escuela Judicial).

## Estructura

- `index.html` — Página principal con las 8 unidades de aprendizaje, competencias y bibliografía.
- `unidad.html?u=N` — Vista de lectura de cada unidad (N = 1 a 8).
- `herramientas/flashcards.html` — Flashcards por unidad para memorizar términos clave.
- `herramientas/quiz.html` — Cuestionario de autoevaluación por unidad.
- `herramientas/glosario.html` — Glosario buscable de términos procesales penales.
- `assets/data/contenido.json` — Fuente única de contenido (unidades, competencias, bibliografía).
- `assets/data/quiz.json` — Banco de preguntas del quiz.
- `assets/data/glosario.json` — Términos y definiciones para el glosario y flashcards.

## Fuente

Contenido basado en el Plan de Estudios 2026 del Consejo de la Magistratura - Escuela Judicial y en el documento oficial del módulo (revisión abril 2025).

## Cómo contribuir contenido

Editar `assets/data/contenido.json` para ampliar las lecturas de cada unidad, y `quiz.json` / `glosario.json` para sumar preguntas o términos.
